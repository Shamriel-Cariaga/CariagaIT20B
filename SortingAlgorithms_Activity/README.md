Briefly explain what your Java program does.
- Kani nga Java program is gipakita nako ang 3 ka basic nga sorting algorithm which is ang Bubble Sort, Selection Sort og Insertion Sort into 1 file. Nag use og 10 array unsorted numbers og gi arrange into ascending order(from gamay to dako), then gidisplay ang original array og ang sorted results sa each sort algorithm.

Explain how Bubble Sort works.
- Ang Bubble Sort is gina compare niya ang numbers sa iyang tapad dayon magswitch if ang first number kay dako kaysa second number. Gapangitaon niya ang dako og i move sa right. Mopadayon ra dayon hangtod ang arrangment is smallest to greatest and maong gi tawag og "Bubble" kay gapatass man ang bubble.

Explain how Selection Sort works.
- Ang Selection Sort ginapangita niya ang pinaka gamay sa array og mao ang i first position. Then pangitaon nasad niya ang next smallest number og mao ang i second position. Then gapadayon and gapadayon lang niya pangitaon sa array ang smallest number para sa next position, sa pangalan pa niya nga "Select".

Explain how Insertion Sort works.
- Ang Insertion Sort ginatake niya isa ka number at a time og i place niya sa corrict position. First, i compare niya sa number before niya before i insert and ang dako nga number mo move sa right, and if ang number is dako na daan naa ra siya sa iyang position. Sa name niya nga "Insert", kuha then i insert sa sakto nga position.

Discuss the differences between the three sorting algorithms.
- Bubble Sort i compare niya sa tapad if dayon switch if ang tapad(2nd number) kay dako.
- Selection Sort pangitaon ang pinaka gamay nga number and then i first position.
- Insertion Sort kuha isa ka number then insert sa sakto nga position.

- I think Insertion ang better if ang numbers already sorted na kay i check ra niya ang each number og dili na need mag ove or switch number.
